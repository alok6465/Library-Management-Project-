# File Viewer - Excel & CSV Reader

A simple Flask web application to view Excel (.xlsx) and CSV files with search functionality and PDF export.

## Features

- Upload and view Excel (.xlsx) and CSV (.csv) files
- Real-time search through data
- Download filtered data as PDF
- Responsive design with Bootstrap 5
- Drag and drop file upload

## Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the application:
```bash
python app.py
```

3. Open browser and go to: `http://localhost:5001`

## Usage

1. Upload an Excel or CSV file
2. Use the search bar to filter data
3. Click "Download PDF" to export current view as PDF
4. Click "Reset" to upload a new file
